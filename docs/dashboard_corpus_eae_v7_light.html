Explorer un concept

Trouver toutes les occurrences d'un mot ou d'une expression dans le corpus, avec extraits contextuels et évolution chronologique.

L'application cherche votre mot ou expression dans le contenu complet des 318 documents indexés. Elle regroupe les occurrences par période pour retracer l'évolution du concept depuis l'origine jusqu'à la compréhension actuelle.
